WorkBuddy Portable 1.0.3 — 紧凑界面修正版
Windows 10/11 x64；社区便携封装，非官方便携发行版。

这次只把字体、框和按钮收小：
正文 18，标题 24，辅助字 14；100% 下进度窗口约 670×400。
正文仅比最初的 16 稍大一点，不再使用上一版的大字体 / 大框。
高 DPI 时本工具最多放大 125%，外框按实际 Windows 标题栏尺寸调整，设置窗口也同步收小。

原功能保留：
主界面就绪后销毁进度窗口，不留启动器托盘。
应用真正退出后回收本次 Job 受管进程、关闭桥接，启动器自动结束，无退出成功确认框。
最小化或隐藏不触发回收；运行期间仍有必要的无界面代理 / 监管。

覆盖升级：
先从应用自己的退出菜单 / 官方托盘退出，等旧启动器进程结束。
只需用本包 WorkBuddy-Portable.exe 覆盖原便携目录中的同名 EXE。
保留 Data、Runtime、tools、Workspace、portable.json 和 Network-Settings.cmd。
有效的 1.0.1 适配运行时直接复用，不因本次调整重新下载或重新适配。
如原目录没有 Network-Settings.cmd，可从本包补入。
启动器版本为 1.0.3，Runtime/current.json 的 wrapper 仍为 1.0.1，正常。

全新使用：完整解压后运行 EXE；首次仍需要联网准备，包内不含离线运行时或个人数据。
两款程序分别放在各自目录，不要混用 Runtime / Data。
网络设置入口：Network-Settings.cmd。
退出后仍请用 Windows 安全删除硬件再拔盘；强拔盘 / 外部服务 / 提权进程不能保证完全收束。

本次 Windows 原生 GUI / Job 测试只编译，未在 Windows 真机执行。
详见 README.md 和 docs/测试与验收.md。
