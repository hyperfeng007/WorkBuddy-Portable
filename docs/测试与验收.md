# WorkBuddy 1.0.3：紧凑界面回调

日期：2026-09-27。仅调整上一版 1.0.2 过大的启动/设置界面；不是运行时或网络升级。

## 当前尺寸

- 正文 22 → **18** 逻辑像素，仅比最初 16 稍大。
- 标题 32 → **24**，辅助文字 18 → **14**。
- 进度内容区 **660×370**；100% 缩放下整个窗口约 **670×400**，确切外框取决于 Windows 主题 / 标题栏。
- 按钮回到 32 高度，去掉大块留白；设置内容区 **620×345**，同样缩小。
- 根据系统 DPI 缩放，本工具额外缩放上限为 **125%**，不再在高 DPI 下成倍放大。通过 AdjustWindowRectEx 添加实际系统外框，避免标题栏挤占按钮。

## 保持不变

`main_windows.go`、`process_windows.go`、`shutdown.go`、代理 / 适配 / 安装 / 复用 / 完整性实现均与 1.0.2 字节一致，窗口消息处理函数也逐字节一致。只修改布局、字体、缩放、显示版本、对应资源和布局测试。

主界面就绪后销毁启动窗口，无启动器托盘；真正退出后回收本次受管 Job、关闭桥接并自动退出；最小化 / 隐藏不触发回收。网络设置仍用 Network-Settings.cmd。原有权限、TLS 和运行时兼容版本 **1.0.1** 不变。
