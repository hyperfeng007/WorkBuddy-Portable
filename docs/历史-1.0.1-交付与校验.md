# 交付与校验

发行：WorkBuddy Portable 1.0.1，Windows 10/11 x64，腾讯国内版 5.6.2.39298511 适配。407 回归已通过，仍待 Windows 实际任务验收。

## 包内

- `WorkBuddy-Portable.exe`：带进度窗口、托盘和网络设置的启动器。
- `tools/7z.exe`、`tools/7z.dll`：固定、未改动的解包工具，运行时验证哈希。
- 不附默认 `portable.json`，避免覆盖旧用户代理设置；不存在时启动器默认 auto。
- `Update-WorkBuddy.cmd`：完全退出后检查官方构建。
- `启动说明.txt`、`README.md`、`docs/`：使用方法、限制与实际测试记录。
- `source/`：完整社区启动器源码、内嵌适配脚本、测试及 Windows 资源。
- `SHA256SUMS.txt`：干净发行包的逐文件 SHA-256；不包含清单自身。

**不包含官方预装运行时、账号数据或密钥。** 首次运行下载约 531 MB 官方包。以后运行时和原始包缓存在 U 盘，优先复用。

ZIP 自身的 SHA-256 在 ZIP 同级的 `.zip.sha256` 文件中，避免自引用。Windows 可用 PowerShell：

```powershell
Get-FileHash .\WorkBuddy-Portable-Windows-x64-v1.0.1.zip -Algorithm SHA256
Get-FileHash .\WorkBuddy-Portable.exe -Algorithm SHA256
```

SHA-256 只能在你信任这份校验清单来源时用于验证文件未变化。它不是腾讯对社区启动器或适配副本的签名。

更改自己的 `portable.json` 后，该文件与发行清单不同是正常的。升级时保留自己的配置、Data 和 Runtime，不要为了匹配发行清单而覆盖用户数据。
