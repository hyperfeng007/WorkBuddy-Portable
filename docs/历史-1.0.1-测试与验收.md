## 复现

Go 1.26.1、Node 24.21.0。在 source/ 中设置：

```text
WBP_TEST_APP       完整、未适配的固定官方应用目录
WBP_TEST_INSTALLER 固定原始 NSIS 包
WBP_TEST_RUNTIME   原始 app.asar 展开目录，含 node_modules
WBP_TEST_NODE      Node 可执行文件绝对路径
WBP_TEST_OUTPUT    用于保存实际适配输出模块的临时目录
TMPDIR            有足够空间的磁盘目录
```

```sh
GOMEMLIMIT=256MiB go test -race -count=1 -v ./...
node --test --test-timeout=20000 tests/adapters.test.mjs
node tests/bootstrap-probe.mjs
go vet ./...
GOOS=windows GOARCH=amd64 go vet ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go test -c -o workbuddy-tests.exe .
```

未设置真实 fixture 环境变量的相关测试会 SKIP，不代表真实包已验证。`go test -c` 只编译测试。
