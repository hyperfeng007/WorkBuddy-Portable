# WorkBuddy Portable 1.0.2：交付与校验

制作日期：2026-09-27。目标 Windows 10/11 x64；社区便携启动器，非官方便携发行版。

## 当前交付

- 启动器：**1.0.2**；有效运行时的适配兼容版本保持 **1.0.1**。
- 启动文字放大；ready 后销毁进度窗口、无启动器托盘；真正退出后回收本次 Job 并自动结束，不需点击成功对话框。
- 必需的无界面桥接 / 监管只在应用运行期间保留。最小化 / 隐藏不触发回收；其他独立实例不按进程名被杀。
- 新增 **Network-Settings.cmd** / `--settings`，独立打开设置。
- 保留上一版运行时适配/网络实现的原始字节，包括 DSH 代理/压缩处理或 WorkBuddy CLI 认证修复；兼容比较见 `ui-release-compatibility.txt`。

## 包内容与升级

包含 EXE、tools 解包工具、Network-Settings.cmd、更新入口、完整源码/测试/资源、许可证、文档和逐文件 SHA256SUMS.txt。

**不包含预装离线官方运行时、个人 Data、账号或默认 portable.json**。新目录首次仍需联网准备；没有配置时默认自动代理，保存设置后生成 portable.json。

已有 1.0.1：退出旧程序并备份，把新的 EXE 和 Network-Settings.cmd 放回原目录；保留 Data、Runtime、tools、Workspace 与个人 portable.json。有效的 1.0.1 运行时直接复用，不为本次 UI 更新重新下载或重新适配。不要只把 EXE 放进新空目录。

更早版本仍按原有迁移/修复规则准备，不把 UI-only 快速复用保证扩大到所有旧版本。详见根目录 `README.md`。

包内 `SHA256SUMS.txt` 覆盖除自身外的所有文件；ZIP 发布时逐项核对并执行 CRC 检查，ZIP 的 SHA-256 在同名 `.zip.sha256` 文件中。
